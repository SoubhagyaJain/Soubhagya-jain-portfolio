LLM Inference Engine

A systems project focused on understanding how modern LLM serving works under real constraints — throughput, latency, batching, KV-cache management, quantization and memory efficiency.

Less about shipping a demo, more about learning the internals: how requests are batched, how memory is managed, and where the bottlenecks actually come from. I'm documenting the trade-offs as I go.
